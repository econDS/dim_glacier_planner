# Dim Glacier Ultimate Planner

เว็บแอปสำหรับวางแผนและคำนวณงบประมาณการทำ **Dim Glacier Weapon** ตั้งแต่ตัวอาวุธ, Enchant Slot 4–2 ไปจนถึงการ Refine พร้อมเปรียบเทียบต้นทุนเป็น Zeny และเงินบาท

> **[เปิดใช้งาน Dim Glacier Ultimate Planner](https://econds.github.io/dim_glacier_planner/)**

## ความสามารถหลัก

- กำหนดราคาวัตถุดิบ ไอเทมสำเร็จรูป และอัตราแลกเปลี่ยน Zeny เป็นเงินบาท
- วางแผน Enchant แบบ "ตอนนี้มีแล้ว → อยากไปถึง" (Slot 4 → Slot 3 → Slot 2 Lv 1–5) เช่น มี Slot 2 Lv 3 แล้ว อยากได้ Lv 5
- สรุปรายการวัตถุดิบที่ต้องเตรียมรวมทุกขั้น ดูเป็นของสำเร็จหรือแตกเป็นวัตถุดิบดิบ และคัดลอกรายการได้
- เลือกวิธีทำ Enchant Slot 4 และ Slot 3 ระหว่าง Coupon กับวัตถุดิบปกติ
- คำนวณค่า Refine จาก Refine Cube, Refinement Device และงบ Refine แบบกำหนดเอง
- เปรียบเทียบราคาที่คุ้มกว่าระหว่างการ Craft และซื้อจากตลาด
- แสดงต้นทุนแยกตามขั้นตอน พร้อมยอดรวมทั้ง Zeny และบาท
- บันทึกค่าล่าสุดอัตโนมัติ
- นำเข้าและส่งออกข้อมูลได้ในรูปแบบ JSON, CSV และ Excel

## วิธีใช้งาน

1. เปิด [หน้าเว็บของโปรเจกต์](https://econds.github.io/dim_glacier_planner/)
2. อัปเดตราคาตลาดและอัตราแลกเปลี่ยนให้ตรงกับข้อมูลปัจจุบัน
3. เลือกขั้นตอน Enchant และวิธีที่ต้องการใช้
4. ระบุจำนวน Refine Cube, Refinement Device หรืองบ Refine เพิ่มเติม
5. ดูต้นทุนรายขั้นตอน การวิเคราะห์ราคาที่คุ้มที่สุด และงบประมาณรวมทั้งหมด

> ราคาภายในเว็บไม่ได้อัปเดตอัตโนมัติ ควรตรวจสอบและกรอกราคาตลาดล่าสุดก่อนคำนวณทุกครั้ง

## การจัดการข้อมูล

ค่าที่แก้ไขจะถูกเก็บไว้ในเบราว์เซอร์โดยอัตโนมัติ หากต้องการสำรองข้อมูลหรือย้ายไปใช้อีกเครื่อง สามารถส่งออกเป็น `.json`, `.csv` หรือ `.xlsx` แล้วนำเข้ากลับผ่านเมนู **จัดการข้อมูล** ได้
